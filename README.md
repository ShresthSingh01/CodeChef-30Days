
# 🏆 30 Days CodeChef – C Programming Practice Challenge
An informal coding challenge organized by my college seniors to improve logic building & problem-solving skills using C language
## About This Challenge

This repository contains my participation in a 30-day coding challenge conducted by our college senior community, where all participants practiced daily problems on CodeChef using C language.
The challenge was designed to build consistency, improve fundamentals, and prepare juniors for competitive programming and placements.

This was not an official CodeChef event, but a student-led peer initiative to create a strong learning environment.

## Objectives

Build a habit of daily coding

Strengthen core C fundamentals

Improve logical thinking and approach to problem-solving

Learn structured problem-solving patterns used in CP

Prepare for future competitions & technical interviews

## 📍 Sample Problem (Example)
// Check if Number is Even or Odd
#include <stdio.h>

int main() {
    int n;
    printf("Enter number: ");
    scanf("%d", &n);

    if(n % 2 == 0)
        printf("%d is Even", n);
    else
        printf("%d is Odd", n);

    return 0;
}
